Beautiful icons.
Just CSS.

A crafted icon set on a 24 px grid, delivered as one stylesheet: about 5 kB gzipped. No icon fonts, no JavaScript, no extra requests. Write <i class="ic ic-heart"> and you’re done.

Browse icons Get started
npm install github:ktsoaela/ok_icons

One element, one class

Icons are plain elements painted with currentColor. Size them with font-size, color them with color.

Three weights

Light, regular and bold strokes. Set them per icon or once on a container: class="ic-bold".

Duotone, for free

Add ic-duotone for a tinted fill. Pick any second color with --ic-secondary.

Tiny and fast

One cached stylesheet. No font loading, no layout shift, no flash of missing glyphs.

Accessible

Works with screen readers, Windows High Contrast mode and users who prefer reduced motion.

SVG when you need it

Every icon also ships as a standalone SVG, in a sprite and as JSON for your framework.

Get started

1

Add the stylesheet

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/ktsoaela/ok_icons@v1/dist/ok-icons.min.css">

Need light or bold? Also add ok-icons-weights.min.css. With npm: import 'ok-icons'.

2

Use an icon

<i class="ic ic-heart" aria-hidden="true"></i>

<button aria-label="Settings">
  <i class="ic ic-settings ic-bold" aria-hidden="true"></i>
</button>
3

Make it yours

.toolbar {
  --ic-size: 20px;
  --ic-color: #5b5bf7;
  --ic-secondary: #e5488f;  /* duotone fill */
}

Classes

ic-light ic-boldStroke weight. Works on the icon or any container.
ic-duotoneAdds a tinted fill. Also works on containers.
ic-xs … ic-2xlSizes: 12, 16, 24, 32, 48 and 64 px.
ic-rotate-90 ic-flip-hRotate (90/180/270) or mirror (h/v).
ic-spin ic-pulse ic-beat ic-bounce ic-shakeAnimations. Turned off for users who prefer reduced motion.

Custom properties

--ic-sizeIcon size. Default 1em.
--ic-colorIcon color. Default currentColor.
--ic-secondaryDuotone fill color.
--ic-secondary-opacityDuotone fill opacity. Default 0.28.
--ic-durationAnimation duration.
